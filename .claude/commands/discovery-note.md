# /discovery-note

Use this command to turn raw customer conversation notes into a structured discovery note.

## Input expected

Raw conversation, meeting notes, or call transcript.

## Output format

# Discovery note — [customer / date]

## 1. Context
- Who spoke?
- Why now?
- What prompted the conversation?

## 2. Confirmed facts
- Fact 1
- Fact 2

## 3. Customer quotes
- Quote 1
- Quote 2

## 4. Problems mentioned
- Problem
- Frequency
- Cost / consequence

## 5. Current workflow
- Inputs
- Steps
- Tools
- Outputs
- Recipients

## 6. Current AI usage
- Tool used
- What it does well
- Remaining gaps
- Risks

## 7. Payment readiness
Green / Yellow / Red

Explain why.

## 8. Next best question
One question only.

## 9. Product implication
What should change in the product hypothesis?
